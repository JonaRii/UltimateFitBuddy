Tracks what's in alpha, what's next, and what's parked.

## Beta (week 2-4)

- Workout templates / routines
- Quick-add favourite foods
- Recipe builder (compose foods into a recipe with custom serving)
- Per-day notes
- Better progress charts (estimated 1RM, volume, body weight trend overlay)
- Photo logging for meals (no AI; just attached image)
- Apple Watch companion for live lifting sessions

## v1.0

- Polished onboarding
- Migration tool to import data from Strong / MyFitnessPal exports
- Optional Siri shortcuts (start workout, log weight, log meal)
- Widgets (today's macros, last workout)

## Parked / nope

- Multi-user accounts
- Social features
- Subscription tier
- Web/Android companions
- AI coach (maybe later, not parked-parked)
